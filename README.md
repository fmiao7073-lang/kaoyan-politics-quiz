# 考研政治刷题 · 单选多选考点汇总

一个纯前端刷题小网页，题库来自《考研政治考前随身背》：

- 专题一「四选一重要考点汇总」：**170 道四选一单选题**
- 专题二「四选二重要考点汇总」：**43 道选 2 项多选题**（马原 23、毛特 4、史纲 10、思修 6）
- 专题三「四选三重要考点汇总」：**52 道选 3 项多选题**（马原 22、毛特 5、史纲 13、思修 12）
- 「易混辨析」：**23 道单选题**，专攻易混考点（起点/关键/基础/前提、公式、分类维度等）

共 **27 个板块、288 题**。

## 功能

- **乱序出题**：每次开始，题目顺序和四个选项的位置都会重新随机打乱
- **即时判分**：单选点选即判分；多选题勾选后点「确认答案」判分，全部选对才得分（漏选、错选均算错），并附解析
- **两种模式**：全套 288 题混合刷，或按板块单独刷
- **错题库**：每轮答错的题自动收录（按题干去重），首页有专门入口；在错题库中练对的题自动移出，直到全部消灭
- **错题重练**：每轮成绩页也可只刷本轮错题，或点某一道单独重练
- **历史成绩**：自动记录每次刷题的时间、模式、得分、正确率和用时，并绘制正确率趋势图
- **云同步**：首页设置一串同步码（4–32 位字母/数字），手机和电脑输入同一个码，历史成绩和错题库自动互通；未开启时数据只保存在当前浏览器（localStorage）

## 本地使用

无需安装任何东西，直接用浏览器打开 `index.html` 即可。
