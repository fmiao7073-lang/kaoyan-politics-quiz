# 考研政治刷题 · 四选一考点汇总

一个纯前端刷题小网页，题库来自《考研政治考前随身背》专题一「四选一重要考点汇总」，共 **170 道四选一单选题**。

## 在线刷题

👉 **https://clkiqibgq5z3y.ok.kimi.link**

## 功能

- **乱序出题**：每次开始，题目顺序和四个选项的位置都会重新随机打乱
- **即时判分**：点选选项立刻显示对错，并附解析
- **两种模式**：全套 170 题混合刷，或按十八大板块单独刷
- **错题重练**：成绩页汇总本轮错题，可一键只刷错题或单题重练
- **历史成绩**：自动记录每次刷题的时间、模式、得分、正确率和用时，并绘制正确率趋势图（保存在浏览器 localStorage，仅当前浏览器可见，清除浏览器数据后丢失）

## 本地使用

无需安装任何东西，直接用浏览器打开 `index.html` 即可。

## 文件结构

```
index.html    页面结构与样式
src/main.js   题库数据（98 题）+ 答题逻辑
```
